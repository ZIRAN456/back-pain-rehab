# 腰痛六大经典运动疗法 · 临床交互指南
> Clinical Interactive Guide for Low Back Pain Rehabilitation

基于循证医学（麦肯基 MDT 疗法、麦吉尔 McGill 核心稳定理论与动力链理论）构建的轻量级纯前端运动康复交互系统。

## 🌟 核心功能
- **适应症三联分群**：盘源性（屈曲不耐受）、节段微失稳（控制障碍）、骨盆代偿（臀肌短板）；
- **对侧动力链仿真**：近侧肢体（加粗实线墨绿）与远侧肢体（点阵虚线冷灰）空间深度解耦；
- **全平台响应式**：完美支持微信内置浏览器、手机移动端触控及 PC 桌面端交互。
